# PNS broken-factor comparison

Verified against the official BAFS PNS/BAFS 290:2025, Table 2:
https://bafs.da.gov.ph/wp-content/uploads/2025/12/PNS-BAFS-290-2025-Paddy-and-Milled-Rice-%E2%80%94-Product-Standard-%E2%80%94-Grading-and-Classification-1.pdf

Broken-kernel maximum percentages, by weight: Premium 5; Grade 1 10; Grade 2 15; Grade 3 25; Grade 4 35; Grade 5 45. Equality stays within the band. Above 45 is displayed as exceeding listed broken limits, not a definitive Off-Grade finding.

The app compares automatic/reviewed **counts** with these numbers only as an experimental analogy. It also accepts user-entered total/broken weights for a weight-based broken-factor comparison. Full grade is always unassessed: other quality factors and the brewers exception are not evaluated.

The standard defines brokens below 75% of average whole-kernel length. The current shape/count classifier is not a calibrated implementation of that rule. A reference-length measurement workflow and broader grading measurements remain future work. Existing visual defect review is retained separately.
